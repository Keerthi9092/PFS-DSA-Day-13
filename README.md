# Day 13 – Stack Implementation Using Files (07-07-2026)

This repository contains my Day 13 practice programs from the Python Full Stack (PFS) Data Structures and Algorithms course. During this session, I learned how to implement a Stack using file handling in Python. The implementation demonstrates how stack elements can be stored and managed using a file while following the LIFO (Last In, First Out) principle.

## Topics Covered

* Stack Data Structure
* LIFO (Last In, First Out)
* Stack Implementation Using Files
* Push Operation
* Pop Operation
* Peek Operation
* Display Stack
* Stack Underflow
* Empty Stack Handling
* File Handling in Python

## Learning Outcomes

* Understood the working principle of a Stack.
* Learned how the LIFO principle is applied in stack operations.
* Implemented Push, Pop, and Peek operations using file handling.
* Practiced reading and writing stack elements to a file.
* Learned how to handle an empty stack and underflow conditions.
* Improved understanding of file handling and data structures using Python.
